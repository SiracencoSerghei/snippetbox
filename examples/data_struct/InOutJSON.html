JSON Encoding & Decoding — super simple explanation

1. What is JSON?

JSON = a way to store data as text so computers can understand each other.

Think of it like a box of labeled information.

2. Example of Go data

type Person struct {
    Name  string
    Email string
}

This is just a Go struct (a container for data).

3. JSON version of that data

{
  "Name": "Mary",
  "Email": "mary@example.com"
}

This is JSON. Same data, different format.

4. Encoding (Go → JSON)

Encoding = converting Go struct into JSON text

jsonData, err := json.Marshal(person)

Result:

{"Name":"Mary","Email":"mary@example.com"}

5. Decoding (JSON → Go)

Decoding = converting JSON text back into Go struct

json.Unmarshal(jsonData, &person)

Now Go understands the data again.

6. Mental model (important)

  • Struct = internal Go format
  • JSON = universal language for APIs
  • Marshal = Go → JSON
  • Unmarshal = JSON → Go

7. Why this exists

Because computers hate each other’s formats.

So JSON is the translator between systems.

8. One-line memory trick

Marshal = pack data

Unmarshal = unpack data
