Go Interfaces — Simple Mental Model

Interface = contract
If a type has required methods → it automatically satisfies the interface.

1. Basic Interface

type Speaker interface {
    Speak() string
}

2. Struct Implementing Interface

type Person struct {
    Name string
}

func (p Person) Speak() string {
    return "Hello, my name is " + p.Name
}
No "implements" keyword in Go. If method exists → it works.

3. Using Interface

func SaySomething(s Speaker) {
    fmt.Println(s.Speak())
}

4. Multiple Types, Same Interface

type Dog struct {}

func (d Dog) Speak() string {
    return "Woof"
}
Person and Dog are different types, but both satisfy Speaker.

5. Mental Model

  • Interface = behavior
  • Struct = data
  • Method = action

speaker.go

package interfaces

// Interface

type Speaker interface {
    Speak() string
}

// Structs

type Person struct {
    Name string
}

type Dog struct {}

// Methods

func (p Person) Speak() string {
    return "Hello, my name is " + p.Name
}

func (d Dog) Speak() string {
    return "Woof"
}

// Function using interface

func SaySomething(s Speaker) string {
    return s.Speak()
}

speaker_test.go

package interfaces

import (
    "fmt"
    "testing"
)

func TestPersonSpeak(t *testing.T) {
    p := Person{Name: "John"}

    result := SaySomething(p)

    fmt.Println("Person says:", result)

    if result != "Hello, my name is John" {
        t.Fatalf("wrong result: %s", result)
    }
}

func TestDogSpeak(t *testing.T) {
    d := Dog{}

    result := SaySomething(d)

    fmt.Println("Dog says:", result)

    if result != "Woof" {
        t.Fatalf("wrong result: %s", result)
    }
}

Run Tests

go test ./examples/interfaces -v
Key Idea:
You don't tell Go "this implements interface".
Go checks methods automatically.
